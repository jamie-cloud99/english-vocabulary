# English learning

讓學習者在情境中取用英文，並把可重用詞彙與實際學習證據保留在 repo。以本檔位置向上三層為 repo 根目錄；以下連結皆指向同一份 repo 資料，不另外複製規則或進度到 skill。

## 新增或整理表達

讀 [README.md](../../../README.md) 的格式、分類與符號規則，再查 [INDEX.md](../../../INDEX.md) 是否已有詞條。有原始語境時先按語境解讀，區分已確認詞義與推斷。

新增或補充詞條後同步索引。值得主動取用的片段補入 [EXPRESSION-LOOKUP.md](../../../EXPRESSION-LOOKUP.md)，依溝通目的放入現有分類；需要新分類時才擴充。同一筆需求保留一個位置。

## 練習與回饋

開始、接續練習或回饋答案前，讀 [PRACTICE.md](../../../PRACTICE.md) 與 [LEARNING-PROGRESS.md](../../../LEARNING-PROGRESS.md)。按目前進度接續，一次一題，優先英文情境自由回答。

依 PRACTICE.md 區分必要修正、可選精準化與溝通內容問題。卡住時採最小提示，接受自然替代說法與簡單英文繞述。

回饋後在 LEARNING-PROGRESS.md 保存有學習價值的原句、情境、提示情況與觀察。使用者表示同意或閱讀解釋不等於應用通過；單次問題先觀察，再有同類證據才列為反覆問題。更新掌握狀態時，同步詞條與索引，保留所依據的驗收證據。

## 完成檢查

檢查修改中的本機 Markdown 連結、索引是否涵蓋詞條，以及新增欄位是否符合 README。調整分類時保留原有需求與例句，避免遺漏或重複。

以目前任務與既有授權決定是否提交及推送；skill 本身不增加外部操作權限。回覆實際保存、驗證與同步結果；跨對話接續需新對話能存取並讀取本 repo。
