# 每日三句話微型寫作

用一個小主題寫三句相連的英文，練習把意思組織成短段落。這是獨立於單字收錄與情境問答的學習支線。

## 三句的任務

| 句子 | 功能 | 寫什麼 |
| --- | --- | --- |
| 第一句 | 主題句 | 直接說出結論、偏好或立場。 |
| 第二句 | 支持句 | 給一個具體例子，說明第一句。 |
| 第三句 | 收尾句 | 寫自己的感想、意義或心得，連回主題。 |

第三句依使用者的設計寫感想即可，不要求機械重複第一句，也不用硬加 In conclusion。沒有固定字數，每句先以自己能自然表達的長度為主。

## 每天怎麼進行

1. 先讀 [寫作進度](PROGRESS.md)，每次給一個簡單英文小主題，不先提供三句範文或要求特定單字。
2. 使用者用英文寫三句。接受簡單說法，卡住時沿用 [一般練習](../PRACTICE.md) 的最小提示方式。
3. 先回饋三句是否連貫、第二句是否有具體例子、第三句是否連回主題。再只挑 1–2 個最值得修正的語言問題，區分必要修正與可選精準化。
4. 提供保留原意、程度相近的三句參考版本，不要求背誦。若句意不確定，先確認或標明假設。
5. 視需要請使用者重寫受影響的句子。回饋可在對話中引用原句，但 repo 只保存修正版與精簡學習重點，不保存使用者原稿。清楚標示修正版是 agent 提供或使用者重寫，不把 agent 版本當成已會使用的證據。

這是低負擔的每日練習目標，由使用者開啟對話時接續。未設定自動提醒或背景出題；漏一天不算答錯，也不要求補寫。使用者提供主題時優先沿用，否則在生活、興趣、人際、學習、旅行、商業等面向輪替，不預設以軟體為主。

## 保存作品與進度

收到首次作答並完成回饋後，才建立 `YYYY-MM-DD.md` 作品檔。以 Asia/Taipei 的實際日期記錄；同日另寫一篇時用 `YYYY-MM-DD-02.md` 等後綴保留各次作品。
作品檔保存題目、提示情況、1–2 個回饋重點與三句修正版；標明版本來源。不把原稿、原稿截錄或逐字錯誤清單寫入檔案，也不轉存到一般學習進度。沒有使用者重寫就標明尚未提交，不代填。
完成回饋後更新 [PROGRESS.md](PROGRESS.md) 的作品連結、目前方向與下一步，僅保留表現摘要。這裡保存寫作的進度；一般練習的證據仍保留在 [LEARNING-PROGRESS.md](../LEARNING-PROGRESS.md)，不把兩邊資料整份複製。

有跨練習重複出現的問題，可在兩邊進度摘要中加入連結。只有符合 [PRACTICE.md](../PRACTICE.md) 驗收標準時，才更新詞條掌握狀態；完成一篇段落本身不代表其中所有詞彙已掌握。

## 如何接續

在能讀取本 repo 的新對話中說「今天三句話」或「繼續微型寫作」。讀取本頁與進度後，先接續尚待回饋的原稿或重寫；若只是先前題目尚未作答，可沿用或由使用者換題，不計失敗。
