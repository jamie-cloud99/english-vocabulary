# 033｜get paged for

## 中文與語感

**V 句型**：因為某個問題或事件收到呼叫、緊急通知，通常需要回應或處理。

原始輸入：`get paged for`。

page 作 **V**，是呼叫某人，可透過呼叫器、廣播或現代通知系統。在工程值班語境，get paged 常指收到需要處理事故的告警；不一定真的使用傳統呼叫器，也不一定發生在半夜。

`get + p.p.` 是被動結構。get 已是原形，paged 必須保留 p.p.，不能寫成 get page。若獨立收動詞，原形才是 page。

## 發音

美式 IPA：`get paged for` /ɡɛt peɪdʒd fər/。

- paged 的 -ed 讀 /d/，整個字一個音節，不是 /ɪd/。
- /dʒd/ 在快語速中可能不易聽清，不能因此把 paged 改成 page。
- for 非重讀時常弱讀 /fər/；get 的 /t/ 在 /p/ 前可能不明顯釋放。

## 常見句型與例句

`get paged for + N / V-ing`：for 引出呼叫原因或觸發事件，不表示因此被責備。

> I got paged for a payment failure at two in the morning.

我凌晨兩點因付款失敗收到緊急通知。

> We shouldn't get paged for problems that can wait until morning.

能等到早上再處理的問題，不應觸發我們的緊急呼叫。

`get paged about + N`：about 強調通知涉及的事情，常與 for 的語意重疊。

> The engineer got paged about a network outage.

工程師收到網路中斷的緊急通知。

`get paged to + V`：說明被叫去做什麼。

> The doctor got paged to assess a patient.

醫生被呼叫去評估病人的狀況。

`page + O` 是主動句：`The hospital paged the doctor.`。

## 近義比較與相關表達

| 表達 | 差異 |
| --- | --- |
| get notified | 收到通知，範圍廣，不一定緊急或需立即回應。 |
| get alerted | 收到警報或警示，是否需要處理由語境決定。 |
| get called in | 被叫來工作或協助，可能需要到場；被 page 不一定需要到場。 |
| be on call | 處於待命、值班狀態，不表示已收到呼叫。 |
| get paged | 收到呼叫，強調事件發生。 |

沒有直接的通用反義詞；`not get paged` 是未收到呼叫，`be off duty` 則是非值勤狀態，兩者不等義。

## 難字估計程度

- **page，V，呼叫某人**：此詞義估計 C1，屬專門工作語境的學習參考，不代表整個片語的官方等級。
