# 030｜underlying

## 中文與語感

**Adj，通常放在 N 前**：潛在的、表象之下的、根本的；作為基礎的。

核心是「表面現象下面，真正存在或支撐它的東西」。不一定指壞事，也不等於尚未發生：underlying problem 可以是已存在、但不容易看見的問題。

原始輸入：`underlying`。本次沒有完整語境，先收常見的 Adj 用法，保留 underlying；它也可以是 V `underlie` 的 V-ing，需看完整句子判斷，不因字尾 -ing 就一律還原。

## 發音

美式 IPA：/ˌʌndɚˈlaɪɪŋ/。主要重音在 /laɪ/。

- /laɪɪŋ/ 包含 /aɪ/ 接 /ɪŋ/，不要漏掉後面的 /ɪŋ/。
- `the underlying cause` /ði ˌʌndɚˈlaɪɪŋ kɔz/：the 在母音前常用 /ði/，可自然接到 underlying；實際讀法依口音、語速與重音而異。

## 常見搭配

| 搭配 | 中文 |
| --- | --- |
| underlying cause / reason | 根本原因；表象背後的原因 |
| underlying problem / issue | 深層問題 |
| underlying assumption | 隱含的、作為推論基礎的假設 |
| underlying principle | 基本原則 |
| underlying health condition | 潛在或既有的健康問題，依語境判斷 |

## 跨情境例句

> We need to address the underlying cause, not just the symptoms.

我們需要處理根本原因，不能只處理表面症狀。

> Their argument was about money, but the underlying issue was a lack of trust.

他們爭論的是錢，但深層問題是缺乏信任。

> The underlying assumption is that customers value speed more than price.

背後的假設是，顧客比起價格更重視速度。

> The two courses share the same underlying principles.

這兩門課有相同的基本原則。

## 近義比較與反義表達

| 表達 | 差異 |
| --- | --- |
| underlying | 強調表象之下的原因、狀態或基礎。 |
| fundamental | 強調根本、核心、重要，不一定有隱而不顯的意思。 |
| hidden | 強調看不見或被隱藏，不一定是原因或基礎。 |
| potential | 可能存在或未來發生；underlying 常指已存在的深層因素。 |
| root cause | 強調追查到的根源；underlying cause 不一定是唯一或最終根源。 |

表象與深層對照時可用 `surface-level`；隱含與明說對照時可用 `explicit`，例如 underlying assumption 與 explicit assumption。沒有適用所有詞義的單一反義詞。

## 與動詞 underlie 的關係

`underlying + N`：Adj 修飾 N。

> Fear underlies their resistance to change.

恐懼是他們抗拒改變的深層原因。

這裡 underlies 是 V，原形為 `underlie`，直接接 O，不加介系詞。變化為 underlie → underlay → underlain；不要與 underlay 的其他獨立用法混淆。

## 難字估計程度

- **underlying**：估計 C1–C2。Cambridge 將「真實存在但不明顯」的 Adj 詞義標示為 C2；此處仍作學習參考，不代表整句難度。

## 一起記

`identify / address the underlying cause`：找出／處理根本原因。
若只是繞過問題，可能只是 [workaround](023-workaround.md)，未必處理 underlying cause。
