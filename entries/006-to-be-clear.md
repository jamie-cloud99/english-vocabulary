# 006｜To be clear

## 中文與語感

說清楚一點、先澄清一下、為了避免誤會。
常放在句首，先提醒對方，接下來要釐清某個重點或明確表達立場。
此處的 clear 是 Adj，表示意思清楚、沒有歧義。

語氣取決於上下文與重音。可以是中性的說明，也可能顯得直接、堅定；反覆對人使用，可能像在糾正或訓話。
加上 `just` 的 `just to be clear` 常用來稍微緩和開場，但不保證聽起來一定柔和。

## 分類與使用方向

- 生活情境：人際與溝通。
- 考試主題：教育與校園、工作與經濟、科技與媒體；此表達可跨主題使用。
- 表達功能：澄清與確認、提出觀點。
- 使用建議：適合口說、討論與解釋立場。正式寫作也可使用，但應確實釐清歧義，不必每段都加。
- 掌握狀態：待確認。

## 發音

美式 IPA：/tə bi klɪr/。

- `to` 通常弱讀為 /tə/；`be` 通常不重讀。
- 片語重音通常落在 `clear`。
- `be clear` 的 /i/ 接 /k/ 順接，中間不加停頓或額外母音。
- 句首的 `To be clear, ...` 後常有短暫停頓，接著說明要澄清的內容。

## 近義表達比較

| 表達 | 意思與差異 |
| --- | --- |
| to be clear | 主動釐清意思、避免誤解，也可強調立場。 |
| just to clarify | 補充澄清細節，常作為比較緩和的開場。 |
| in other words | 換句話說，重述前面的內容，不一定是在糾正誤解。 |
| to be precise | 準確地說，修正或縮小數字、用字等細節。 |
| to be honest | 坦白說，強調誠實表達感受或看法，不是澄清意思。 |

沒有自然且固定的反義表達。

## 常見用法與例句

### To be clear, + 子句

> To be clear, the deadline is Friday, not Monday.

先說清楚，截止日是星期五，不是星期一。

> To be clear, I support using AI as a tool, but people should still check its answers.

先澄清一下，我支持把 AI 當作工具使用，但人們仍應查核它的回答。

### Just to be clear, + 確認問題

> Just to be clear, are we meeting online or in person?

我確認一下，我們是線上開會，還是實體見面？

用問題確認理解；與直接陳述自己的立場不同。

## 一起記

- `To be clear, ...` → 我先把意思說清楚。
- `Just to be clear, are you saying ...?` → 我確認一下，你的意思是……嗎？
- `In other words, ...` → 我換個方式說。
