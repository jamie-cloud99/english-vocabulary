# 010｜official documentation

## 中文與語感

官方文件、官方提供的一套說明資料。
`official` 是 Adj；`documentation` 是不可數 N。
在軟體語境，通常指官方提供的操作指南、API 說明、安裝步驟等，不特指一份檔案。
在其他語境，`documentation` 也可指證明資料或書面紀錄，不能一律翻成使用手冊。

## 分類與使用方向

- 生活情境：工作與協作。
- 考試主題：科技與媒體、工作與經濟。
- 表達功能：澄清與確認、證據與推論。
- 使用建議：向他人索取工具說明或查證功能時適用。官方文件可以說明用途與限制，但不能單靠它證明工具適合取代團隊現有測試。
- 掌握狀態：待確認。本次由使用者詢問 AI 工具資料的練習延伸收錄。

## 發音

美式 IPA：/əˈfɪʃəl ˌdɑkjəmənˈteɪʃən/。

- `official` 重音在 /fɪʃ/；`documentation` 主重音在 /teɪ/。
- `official` 開頭弱讀為 /ə/；兩字字尾的 `-al`、`-tion` 都含弱母音 /ə/。
- `official documentation` 的 /l/ 接 /d/ 順接，中間不另加母音。
- `the official documentation` 中，`the` 在母音 /ə/ 前常讀 /ði/，與 official 連接。

## document 與 documentation 比較

| 表達 | 意思與差異 |
| --- | --- |
| a document | 一份具體文件，可為 PDF、報告或其他書面資料。document 是可數 N。 |
| the official document | 某份可辨識的官方文件；上下文通常已指出或足以確認是哪一份。 |
| official documents | 多份官方文件，例如申請所需的證件或書面資料。 |
| official documentation | 官方提供的整體說明或書面資料；documentation 是不可數 N。 |
| a user guide / manual | 一份針對操作的指南或手冊，比 documentation 範圍窄。 |

`document` 並非不能用，選字取決於要指「一份具體文件」還是「整體說明資料」。
此處不用 `a documentation` 或 `documentations`。若要數量化，可說 `a documentation page`、`two user guides`，或直接指出具體文件。

此表達沒有固定反義詞；`unofficial documentation` 表示非官方文件，區分的是來源，不代表內容必然不正確。

## 常見用法與例句

### share / read / check the official documentation

> Could you share the tool's official documentation?

可以提供這個工具的官方說明文件嗎？

> I'd like to read the official documentation before evaluating the tool.

我想先閱讀官方文件，再評估這個工具。

### according to the official documentation

> According to the official documentation, the tool supports automated testing.

根據官方文件，這個工具支援自動化測試。

### 特指一份 document

> Could you send me the official document describing its security features?

可以寄給我那份介紹其安全功能的官方文件嗎？
