# 024｜gripe

## 中文與語感

**N，可數**：抱怨、不滿之處。
**V**：抱怨、發牢騷，常帶反覆抱怨、讓人厭煩的語感。

兩種用法都較口語。`My only gripe is ...` 可以只是點出唯一不滿，不一定表示生氣或問題嚴重。用 gripe 描述別人的申訴，可能讓人覺得你在淡化其問題；正式場合可改用 complaint 或 concern。

## 分類與使用方向

- 生活情境：人際與溝通。
- 考試主題：工作與經濟、社會與公共政策。
- 使用建議：適合日常對話、評論或非正式工作討論；正式申訴通常用 complaint。
- 掌握狀態：待確認。

## 發音

美式 IPA：/ɡraɪp/。N 與 V 相同。

- 一個音節，母音是 /aɪ/，不是 grip 的 /ɪ/。
- `gripe about` /ɡraɪp əˈbaʊt/ 中，/p/ 可接 about 開頭的弱母音 /ə/。
- `my only gripe is` 的 /p/ 可接 is 的 /ɪ/，中間不必停頓。

## 近義詞比較與反義表達

| 表達 | 差異 |
| --- | --- |
| complaint，N | 抱怨、申訴，較通用，可用於正式程序。 |
| complain，V | 抱怨，比 gripe 中性。 |
| grievance，N | 因不公平待遇產生的不滿，常較嚴肅或正式。 |
| grumble，V / N | 嘟囔、抱怨，與發牢騷的語感接近。 |
| concern，N | 擔憂或關切，可較中性地提出問題，不一定是抱怨。 |

方向相反可用 `praise`（讚揚）或 `compliment`（稱讚），但不是每個句型都能直接替換。

## 常見用法與例句

### My only / main / biggest gripe is that + 子句

> My only gripe about the exhibition is that the tickets are too expensive.

我對這個展覽唯一的不滿是票價太高。

### have a gripe about / with + N

> Customers have a few gripes about the delivery service.

顧客對配送服務有幾項不滿。

about 常介紹抱怨的主題；with 常指出不滿所針對的事物，兩者有重疊，不必硬分成完全互斥的規則。

### gripe about + N / V-ing

> He keeps griping about having to wash the dishes.

他一直抱怨得洗碗。

### gripe that + 子句

> Commuters gripe that the buses are always late.

通勤者抱怨公車老是誤點。

## 難字估計程度

- **gripe** /ɡraɪp/：N / V，抱怨、不滿；發牢騷。估計 C1。

## 一起記

`My only gripe is ...` → 我唯一不滿的是……。
`Stop griping about it.` → 別再為這件事發牢騷。語氣直接，對他人使用時注意關係與場合。
