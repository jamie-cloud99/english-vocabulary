# 028｜What makes it worthwhile is ...

## 中文與語法

原始學習片段：`What makes it worthwhile is`。

> What makes it worthwhile is how it helps us appreciate the ordinary moments we might otherwise overlook.

讓這件事值得的，是它幫助我們珍惜那些原本可能忽略的平凡時刻。

`What makes it worthwhile` 整個子句作主詞，意思是「讓它值得的事物／原因」，不是問句。結構接近 `The thing that makes it worthwhile is ...`。

- `what` 是 makes 的主詞。
- `it` 是 makes 的 O，指前文提到的事情；相機語境可指買相機、用相機記錄生活這件事。
- `worthwhile` 是 Adj，作 O 的補語：`make + O + Adj`。
- `is` 後交代具體價值，可接 N 片語或子句。

`What makes + O + worthwhile is ...` 可換 O。完整句型保留原貌；其中動詞原形為 make、be。

## 發音

`What makes it worthwhile is` /wʌt meɪks ɪt ˌwɝθˈwaɪl ɪz/。
makes it 的 /s/ 可接 /ɪ/；worthwhile 的主要重音在 while，不必在 is 前刻意停頓。

## 近義比較與相關表達

- `It's worthwhile because ...`：直接說值得及原因。
- `What makes it worthwhile is ...`：把焦點放在「究竟什麼讓它值得」。
- `worth + N / V-ing`：`It's worth the effort.`、`It's worth trying.`。
- `worthwhile` 是 Adj：`a worthwhile experience`；不能直接用 worth 替換這裡的 worthwhile。
- 相反意思可用 `not worthwhile` 或 `not worth the effort`，句型不同。

## 跨情境例句

> What makes the trip worthwhile is the time we get to spend together.

讓這趟旅行值得的，是我們能共度的時光。

> What makes the training worthwhile is that we can apply it immediately.

讓這項培訓值得的，是我們能立刻把所學用上。

- **worthwhile** /ˌwɝθˈwaɪl/：Adj，值得花時間、金錢或精力的。估計 B2。
