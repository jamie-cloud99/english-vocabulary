# 008｜serious consequence

## 中文與語感

嚴重後果。`serious` 是 Adj，`consequence` 是可數 N，這個詞義常帶負面語感。
概括可能的影響時，常用複數 `serious consequences`。
單數也正確，但通常需要冠詞或其他限定詞，例如 `a serious consequence`。

## 分類與使用方向

- 生活情境：風險與應對。
- 考試主題：科技與媒體、健康與心理、工作與經濟。
- 表達功能：因果、問題與對策。
- 使用建議：適合討論決策、政策或錯誤的重大影響。比 `horrible outcome` 更適合中性的工作風險討論。
- 掌握狀態：待確認。本次從付款功能的應用練習延伸收錄。

## 發音

美式 IPA：/ˈsɪriəs ˈkɑnsəkwəns/。
複數：/ˈsɪriəs ˈkɑnsəkwənsɪz/。

- 兩字都在第一音節有字重音；句重音依強調內容改變。
- `serious` 尾音節含 /ə/，`consequence` 中間也含弱母音 /ə/。
- `serious consequences` 的 /s/ 接 /k/ 順接，不在中間加母音。
- 複數字尾讀 /ɪz/，增加一個音節，不只是把原有的 /s/ 拉長。

## 近義詞比較與反義表達

| 表達 | 差異 |
| --- | --- |
| serious consequences | 嚴重後果，通用且適合工作或論述語境。 |
| severe consequences | 嚴重、嚴厲的後果，語氣較強。 |
| disastrous consequences | 災難性後果，比 serious 更強。 |
| significant consequences | 重大、顯著影響，不一定是負面。 |
| outcome | 結果，較中性，常著重最後的結果。 |
| result | 結果，範圍廣，可正面或負面。 |

表示程度相反可用 `minor consequences`（輕微後果）；若指正面影響，可用 `beneficial effects`，但不是完全對稱的反義詞。

## 常見搭配與例句

### have serious consequences for + N

> A payment error could have serious consequences for our customers.

付款錯誤可能給我們的客戶帶來嚴重後果。

### face the consequences of + N / V-ing

> The company must face the consequences of ignoring security warnings.

公司必須面對忽視安全警告的後果。

### a serious consequence of + N / V-ing

> Data loss is a serious consequence of inadequate backups.

資料遺失是備份不足的一項嚴重後果。

### result in serious consequences

> Releasing the feature without testing could result in serious consequences.

未經測試就發布這項功能，可能造成嚴重後果。
