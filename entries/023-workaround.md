# 023｜workaround

## 中文與語感

**N，可數**，變通辦法、繞過問題的方法。讓事情能繼續進行，但沒有完全解決問題本身。
常是暫時措施，但不代表一定很快停用，也不保證便宜、容易或安全。語境可為科技、商業流程或日常設備限制。

## 分類與使用方向

- 生活情境：思考與決策。
- 考試主題：工作與經濟、科技與媒體。
- 使用建議：需要明確表達「先繞過障礙」時使用。單純有另一個選項，不一定就叫 workaround。
- 掌握狀態：待確認。

## 發音

美式 IPA：/ˈwɝkəraʊnd/。

- 主重音在 /wɝk/，中間音節弱讀 /ə/。
- `a workaround` /ə ˈwɝkəraʊnd/ 中，a 弱讀 /ə/。
- `workaround for` 中尾音 /d/ 接 /f/ 時可能不完全釋放；非重讀的 for 常讀 /fər/。

## 近義詞比較與對比

| 表達 | 差異 |
| --- | --- |
| workaround | 繞過問題，讓事情能做下去，不完全解決原問題。 |
| solution | 解法、方案，範圍較廣；不必然代表永久解法。 |
| fix | 修正、修理；可能暫時也可能徹底，需看上下文。 |
| alternative | 替代選項，不一定存在需要繞過的問題。 |
| stopgap measure | 權宜措施，特別強調暫時應急。 |

沒有固定反義詞。可以用 `a permanent fix` 或 `a lasting solution`，與只先繞過問題的做法對比。

## 常見搭配與例句

### a workaround for + N

> We found a workaround for the booking problem: call the hotel directly.

我們找到處理訂房問題的變通方法：直接打電話給飯店。

### come up with a workaround

> The shop came up with a workaround when its card machine stopped working: customers could pay by bank transfer.

刷卡機故障後，店家想出變通辦法，讓顧客用銀行轉帳付款。

### a temporary workaround

> Using a desk lamp is a temporary workaround until the ceiling light is repaired.

在天花板燈修好前，使用檯燈是暫時的變通辦法。

## workaround 與 work around

- `workaround`：此詞條以一個字的 N 收錄，例如 `We need a workaround`。
- `work around + O`：V 片語，繞過或設法應對限制，例如 `We need to work around the limited opening hours`（我們得想辦法配合有限的開放時間）。

N 與 V 片語的拼寫在這種區分下不同，不把 N 的 workaround 機械改成動詞形式。

## 難字估計程度

## 一起記

`This is a workaround, not a permanent fix.`

這是變通辦法，不是永久修正。
