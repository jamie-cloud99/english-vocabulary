# 009｜like new

## 中文與語感

像新的一樣，常描述舊物保養、修復後的外觀或運作狀態。
不是說物品從未使用，而是說它目前的狀態接近新品。

## 分類與使用方向

- 生活情境：日常生活。
- 考試主題：工作與經濟，例如二手買賣與消費。
- 表達功能：比較與取捨，對比現有物品與新品的狀態。
- 使用建議：日常口說與商品描述皆自然。依想表達外觀或功能，搭配 `look` 或 `work`。
- 掌握狀態：待確認。本次由相機描述練習延伸收錄。

## 發音

美式 IPA：/laɪk nuː/。

- 此表達通常沒有固定的弱讀變化，常把重音放在 `new`。
- `like new` 的 /k/ 接 /n/ 時，/k/ 可能不完全釋放，不必在兩者之間加母音。
- `like a new one` /laɪk ə nuː wʌn/ 中，`a` 通常弱讀為 /ə/。

## 近義表達比較

| 表達 | 意思與差異 |
| --- | --- |
| like new | 像新的一樣，可描述外觀、整體狀態或運作表現。 |
| as good as new | 狀態恢復或維持得像新的一樣，常見於維修或整理後。 |
| in pristine condition | 保存得完好如新，較正式，著重狀態極佳。 |
| in good working order | 功能正常，不保證外觀或效能與新品相同。 |
| brand new | 全新的，通常指新品，而非用過但保存良好。 |

相反描述可依情境選 `worn out`（用舊、磨損嚴重）或 `in poor condition`（狀態不佳），不是固定的對稱反義詞。

## 常見用法與例句

### look like new

> The camera has no scratches and still looks like new.

這台相機沒有刮痕，看起來仍像新的一樣。

### work like new

> After the repair, the camera works like new.

修理後，這台相機運作起來像新的一樣。

### be like new

> I've used it for five years, but it's still like new.

我用了五年，但它仍像新的一樣。

### like-new + N

> The camera is in like-new condition.

這台相機的狀態接近全新。

放在 N 前作複合修飾語時常寫成 `like-new`；`It looks like new` 則不加連字號。

## 使用提醒

`It works like new` 與 `It works like a new one` 都可以；後者的 `one` 代替前文中的單數可數 N，前面需要 `a`。不用 `like new one`。

## 一起記

- `have no scratches` → 沒有刮痕。
- `scratch-free` → 無刮痕的，可形容表面，例如 `a scratch-free screen`。
- `spotless` → 沒有髒污，不保證沒有刮痕。
