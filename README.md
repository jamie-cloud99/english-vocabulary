# 英文單字與慣用語筆記

隨時收集遇到的英文單字、搭配詞與慣用語，以繁體中文整理成可查閱的單字本。
參考 system-design-study-group 的獨立 Markdown 筆記方式，索引另外存放。

## 單字本索引

前往 [單字本索引](INDEX.md) 瀏覽全部詞條與分類。README 保留整理規則，各詞條內容存放於 `entries/`。
腦中有意思卻想不起英文時，可用 [表達需求查找](EXPRESSION-LOOKUP.md)，從中文意圖尋找可組合的英文片段。

## 分類方式

TOEFL 與 IELTS 共用一套詞條，依生活情境、考試主題與表達功能交叉查閱。以下是本單字本的學習分類，不是官方題庫分類，也不代表出題頻率。

### 生活情境

每筆選一個主要情境，語意主題與語氣則用少量標籤補充。

| 情境 | 內容 |
| --- | --- |
| 日常生活 | 習慣、生活安排、消費 |
| 人際與溝通 | 信任、表達、衝突、協商 |
| 情緒與心理 | 情緒反應、心態、動機 |
| 工作與協作 | 任務、進度、責任、合作 |
| 思考與決策 | 判斷、取捨、推論 |
| 風險與應對 | 警覺、預防、危機處理 |
| 社會與知識 | 科技、教育、環境等議題 |

### 考試主題

依實際用法選零到多個主題，不為了分類而硬套。

| 主題 | 內容 |
| --- | --- |
| 教育與校園 | 學習方法、大學生活、教育制度 |
| 工作與經濟 | 就業、職涯、商業、消費 |
| 科技與媒體 | 網路、AI、隱私、新聞 |
| 環境與自然 | 氣候、生態、能源、保育 |
| 健康與心理 | 醫療、生活習慣、情緒 |
| 社會與公共政策 | 城市、交通、法律、社會問題 |
| 文化與歷史 | 藝術、傳統、歷史變遷 |

### 表達功能與掌握狀態

`functions` 記錄表達用途，可複選或留空。初始選項為「因果」、「比較與取捨」、「提出觀點」、「問題與對策」、「證據與推論」，遇到新用途再擴充。

`status` 依使用者回饋更新，不因已收錄或讀過解釋就自動判定掌握。

- 待確認：尚未確認理解與使用能力，新增時預設此值。
- 看得懂：能在閱讀或聽力語境理解。
- 會使用：能在口說或寫作中自然使用。

詞條正文補充主題適用語境、口說或寫作使用建議，以及近義、反義或相關詞群。相關表達已有獨立詞條時，加入連結。

## 每筆內容

- 中文意思、詞性或片語類型、語氣與自然度。
- 美式 IPA，以及連音與弱讀提示。發音不使用中文諧音。
- 近義詞比較，以及適用時的反義詞或反義表達。
- 常見搭配與用法，附英文例句及中文翻譯。
- 詞性標籤與句型統一使用下方符號表；一般中文解說保留自然敘述。
- 只對難字列出「估計程度」，使用 CEFR 等級。不評整個片語，也不附托福／雅思分數對照。
- 「難字估計程度」優先標示使用者貼上的表達中的難字；例句中的額外難字如需解釋，另列為「例句補充」，不取代主要學習詞彙。沒有難字時不硬列。

CEFR 程度是學習參考估計，不代表官方評級。連音與弱讀是可能的口語變化，依語速、重音與口音而異。

## 詞性與句型符號

| 符號 | 意思 |
| --- | --- |
| N | 名詞 |
| V | 動詞；句型中單獨使用時表示原形動詞 |
| Adj | 形容詞 |
| Adv | 副詞 |
| Prep | 介系詞 |
| Pron | 代名詞 |
| S | 主詞 |
| O | 受詞 |
| V-ing | 動詞的 -ing 形式，依句型可為動名詞或現在分詞 |
| p.p. | 過去分詞，包含不規則變化 |

例如 `afford + N`、`cannot afford to + V`、`avoid + V-ing`。
符號只取代詞性與句型位置，實際英文用字保留原文，例如 `to + V` 的 `to` 不改寫為 `Prep`。
一般中文說明仍可用「名詞」「動詞」等詞，讓解說容易閱讀。

## 收錄方式

每個詞條存成 `entries/NNN-kebab-case-expression.md`，編號依收錄順序遞增並保持穩定。
同一表達重複出現時，補充原詞條的語境或例句，避免重複收錄。
使用者提供的上下文優先決定詞義；有歧義時，清楚區分不同解讀。
保留原始輸入。遇到較少見的說法，補上自然替代用語並說明差異。
新增或更新詞條後，同步維護 [INDEX.md](INDEX.md)。詞條清單集中於該檔案，不在 README 重複列出。
詞條或練習中出現值得重複使用的表達時，補入 [EXPRESSION-LOOKUP.md](EXPRESSION-LOOKUP.md)。這份查找頁依表達需求組織，不要求逐字背誦例句。

## 應用練習

練習以「有意思 → 主動取用英文」為主，先給情境，不給目標詞彙。允許使用自然的替代說法，不要求套入特定詞條。
卡住時，先讓使用者指出想表達的中文片段，再提供最小的英文搭配提示，讓使用者自行完成句子。
回饋後換情境再試，並安排隔幾天無提示的重試。不以背出參考例句判定掌握。
掌握狀態依實際證據更新；使用過提示的回答不算無提示應用。文字練習不代表已驗證口說能力。

## 詞條資料欄位

每筆以 YAML front matter 保存下列欄位，正文為主要內容來源，方便日後匯出結構化資料。

| 欄位 | 格式與用途 |
| --- | --- |
| id | 字串，穩定的收錄編號 |
| expression | 字串，原始單字或表達 |
| type | 字串，例如 word、collocation、idiom、phrasal-verb |
| added | YYYY-MM-DD 字串，收錄日期 |
| category | 字串，一個主要生活情境 |
| exam_topics | 陣列，適用的考試主題 |
| functions | 陣列，表達功能 |
| status | 字串，待確認、看得懂或會使用 |
| tags | 陣列，語意主題與語氣 |

目前以 Markdown 保存與查閱，沒有自動同步或背景收錄服務。
